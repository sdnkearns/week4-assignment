  compile as:

  run as:
    go run anscombe_quartet_analysis.go

Management Recommendation
  Running this regression is much faster in Go compared to R and python. When working with smaller datasets like this, Go is likely the best option, performance-wise.
  Because the datasets in The Anscombe Quartet are small, this test isn't particularly informative about the performance of medium-sized datasets or larger
  I would recommend further testing with larger datasets to get a better understanding of performance on more realistically sized data.
